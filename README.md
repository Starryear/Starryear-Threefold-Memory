# Starryear-Threefold-Memory

A travel-photo memory triptych skill by Starryear.

It reconstructs one source photograph through three connected layers:

1. **What I saw** — expressive perception
2. **What happened** — the unchanged photographic evidence
3. **What stayed** — a relational memory atlas

The complete prompt system, references, composition script, and ten visual examples are included in the downloadable skill package.
